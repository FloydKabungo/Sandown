# Sandown Retail Crossing

Static multi-page website for Sandown Retail Crossing, including the official logo and original floor plan.

## Pages

- Home
- Store Directory
- Leasing
- Exhibitions
- Floor Plan
- Contact

## Publish with GitHub Pages

1. Unzip this package.
2. Create a GitHub repository.
3. Upload **all files and folders inside the unzipped folder** to the repository root.
4. Commit the files to the `main` branch.
5. Open **Settings → Pages** in GitHub.
6. Under **Build and deployment**, select **Deploy from a branch**, then choose `main` and `/ (root)`.

The site paths are prepared to work both on a custom domain and at a GitHub Pages project URL such as `https://username.github.io/repository-name/`.

The enquiry forms open the visitor's email app with the submitted details filled in. Once the final public domain is known, add a `sitemap.xml` with that domain and reference it in `robots.txt`.
